# Normaltown USA — website

Static blog for [normaltownusa.com](https://www.normaltownusa.com). No platform fees:
posts are plain files, the site is generated by one Python script, and a free host
(Cloudflare Pages) serves it. Publishing a post = commit + push.

## How it works

- **Content lives in `Posts/<year>/<month>/<day>/`** — each post is a folder with:
  - `article.md` — the post (first `# ` line is the title)
  - `publish-beehiiv.md` — supplies the URL slug, subtitle, meta description, image alt
  - one `.png` — the hero image
- **`build.py`** reads every post + the copy in `site/`, applies the brand, and writes
  the finished website to **`dist/`**. Zero dependencies (Python 3 standard library only).
- **`dist/` is committed** and served as-is, so the host needs no build step.

## Publish a new post

1. Add the post folder under `Posts/…` (article.md + publish-beehiiv.md + image.png).
2. Rebuild:
   ```
   python3 build.py
   ```
3. Preview locally (optional):
   ```
   python3 serve.py     # then open http://127.0.0.1:8787
   ```
4. Commit and push:
   ```
   git add -A && git commit -m "Add post: <title>" && git push
   ```
   Cloudflare Pages redeploys automatically in ~1 minute.

## Hosting (Cloudflare Pages) — one-time setup

- Create application → Pages → **Connect to Git** → pick this repo.
- **Build command:** *(leave empty)*
- **Build output directory:** `dist`
- **Custom domains** → add `normaltownusa.com` and follow the DNS steps.

Brand is locked in `build.py` / `brand/`: canvas `#0F0F0F`, text `#FFFFFF`,
accent cyan `#2DD4FF`, Manrope. One idea per graphic, lots of negative space.
