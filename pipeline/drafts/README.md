# Drafts

Posts that are written but must NOT go live yet. Nothing in this folder is picked up by
`build.py` (it only reads `Posts/<year>/<month>/<day>/`), so a draft here cannot be
published by the daily workflow by accident.

To publish one: verify whatever it says needs verifying, then move it into
`Posts/<year>/<month>/<day>/` with a `publish.md` and a hero image, and rebuild.
